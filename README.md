# Ank Jyotish · अंक ज्योतिष

A Vedic numerology web app. Enter a name and date of birth to get:

- **Moolank** (root number), **Bhagyank** (destiny number) and **Namank** (name number, Chaldean values)
- Name harmony check against the birth numbers
- The Vedic grid (3‑1‑9 / 6‑7‑5 / 2‑8‑4) with missing and repeated numbers
- Ruling graha profile: day, colour, ratna, metal, devta, direction, beej mantra, remedies
- Compatibility with Moolanks 1–9 and the personal year number

Plain HTML, CSS and JavaScript in one file. No build step.

## Deploy on Vercel

Import this repo in Vercel, keep Framework Preset as **Other**, and deploy. No build command or output directory needed.
